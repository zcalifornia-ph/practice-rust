## Detailed Change Notes

## 1) New Primitive Data Types Exercise

Added `practice-rust/src/u1-primitive-data-types/integers.rs` with:

- integer type notes (`i8..i128`, `u8..u128`)
- mutable variable declarations with and without initialization
- signed/unsigned assignment examples
- explicit reminder that negative values are invalid for unsigned integers
- basic `bool` equality check and `char` value output

The file includes inline commentary intended for beginner review while reading and running the program.

## 2) Execution Baseline for the Exercise

Observed output from running `integers.exe`:

```text

Is a equal to 7?: true
Character: c
```

This confirms the expected value flow for the sample code.
